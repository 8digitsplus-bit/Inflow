**Key Technical Concepts**
- **Agentic AI with Multi-Tool Use:** An advanced system where an LLM, guided by a system prompt, autonomously selects and executes from a predefined set of Python functions (tools) to answer complex queries.
- **Persistent Agent Memory:** Storing key facts about a user in a separate  DB collection and injecting them into the system prompt for subsequent conversations to provide context-aware, personalized responses.
- **Automated Issue Escalation:** A rule-based system within the agent's prompt that triggers an  tool when certain keywords or unsolvable scenarios are detected, creating a formal support ticket and notifying the user.
- **Recharts Deep Debugging:** Resolved a persistent UI issue by identifying the root cause not as the tooltip container's background but as the  cursor's default  property, demonstrating a deeper level of component analysis.
- **Large-Scale Coordinated Refactoring:** A systematic process of updating multiple backend endpoints first, followed by rewriting their corresponding frontend pages one by one to align with a new product requirement for differentiated metrics.
